# Images

Les logos de partis et les photos de personnalités vivront ici.

Règles impératives (détail dans REGLES.md §8) :

- uniquement des fichiers sous licence libre (Wikimedia Commons), avec le droit à l'image vérifié ;
- si aucune image licite n'est disponible, ne rien ajouter : l'interface affiche une silhouette neutre.

Convention de nommage :

- logos : `assets/images/logos/<id-du-parti>.svg` (ou `.png`)
- photos : `assets/images/photos/<id-de-la-personnalite>.jpg`
