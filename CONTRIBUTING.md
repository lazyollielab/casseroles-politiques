# Contribuer

Toute proposition est bienvenue, à condition de respecter `REGLES.md`. Le projet refuse toute contribution non sourcée ou pénalement risquée (diffamation, présomption d'innocence bafouée).

## Ce qu'il faut

- Une source publique, stable et datée pour chaque fait ajouté.
- Le statut exact et à jour de la procédure.
- Un ton strictement factuel dans les résumés.

## Comment proposer

1. Par issue : décrire l'ajout ou la correction, joindre les sources.
2. Par pull request (avancé) : modifier le fichier concerné dans `data/` en respectant `data/SCHEMA.md`. La validation automatique doit passer.

## Processus

Chaque proposition passe par une relecture humaine avant publication. Une proposition peut être refusée si le sourçage est insuffisant, même factuellement exacte.

## Ce qui est refusé d'office

- Rumeurs, rapprochements non étayés, interprétations.
- Photos sous licence incompatible ou sans droit à l'image vérifié.
- Toute donnée sur une procédure en cours sans source institutionnelle ou de presse établie.
