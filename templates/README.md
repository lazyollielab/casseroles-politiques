# Templates

Les gabarits de pages (cards, slider des affiliations, page de synthèse des chiffres) seront construits ici en phase 2.

Ils liront les trois fichiers de `data/` et n'en dépendront que par leurs `id`. Aucune donnée ne doit être codée en dur ici : si une information figure dans un template, elle est au mauvais endroit et doit déménager dans `data/`.
